# SQL Seminars and Homework

Учебный репозиторий по курсу **«Базы данных и SQL»**.  
Внутри собраны материалы по семинарам и домашним заданиям: создание таблиц, выборки, сортировка, агрегации, `JOIN`, представления, оконные функции, CTE, процедуры, функции и транзакции.

## Что изучается

### Seminar 1
Базовые `SELECT`-запросы, выборка по условию, работа с `LIKE`, выбор отдельных столбцов, фильтрация по имени и значению стипендии.
В домашней работе — создание таблицы с мобильными телефонами, вставка данных, фильтрация по бренду, диапазонам и шаблонам строк.

### Seminar 2
Создание и изменение таблиц, `ALTER TABLE`, переименование таблиц, внешние ключи, `CASE`, `IF`.
В домашней работе — классификация заказов по размеру и расшифровка статусов заказов. 

### Seminar 3
Сортировка, `DISTINCT`, `LIMIT`, агрегатные функции (`SUM`, `COUNT`, `AVG`, `MAX`, `MIN`), `GROUP BY`, `HAVING`.
В домашней работе — задачи по продавцам, клиентам, заказам и дополнительная практика с сортировкой и группировкой сотрудников.

### Seminar 4
Соединения таблиц: `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `CROSS JOIN`, а также `UNION`, `UNION ALL`, `IN`, `NOT IN`, `EXISTS`.
В домашней работе — группировка автомобилей и поиск строк, отсутствующих в другой таблице.

### Seminar 5
CTE, рекурсивные CTE, оконные функции (`ROW_NUMBER`, `RANK`, `DENSE_RANK`, `NTILE`, `LEAD`), аналитические запросы.
В домашней работе — `VIEW`, выборки по диапазону дат и вычисление времени до следующей станции с помощью оконной функции. 

### Seminar 6
Хранимые процедуры, пользовательские функции, транзакции и циклы. В файле реализованы процедура приветствия по времени суток, функция для чисел Фибоначчи, пример перевода средств между счетами и процедура с циклом.

## Для кого этот репозиторий

Репозиторий подойдет:

- студентам, изучающим SQL с нуля;
- тем, кто хочет быстро повторить основные конструкции SQL;
- начинающим аналитикам и backend-разработчикам для практики запросов;
- преподавателям и наставникам как набор коротких учебных примеров.

## Как использовать

1. Откройте нужную папку семинара.
2. Запустите `.sql`-файл в своей СУБД.
3. Изучите примеры из `seminar*.sql`.
4. Сверьтесь с решениями в `homework*.sql`, если файл домашней работы присутствует.

## Что понадобится

Для выполнения примеров нужна SQL-СУБД с поддержкой конструкций, используемых в репозитории.  
По синтаксису (`AUTO_INCREMENT`, `DELIMITER`, процедуры, оконные функции, CTE) материалы ориентированы на **MySQL 8+** или совместимую среду.
